# Python Aulas 🐍

Meus estudos de Python durante o curso de Engenharia de Software.
Cada arquivo é um exercício que eu escrevi, rodei e testei no VS Code.

## O que já estudei

- Terminal do VS Code e execução de arquivos `.py`
- `print()` e `input()`
- Variáveis e tipos (`str`, `int`, `float`)
- Conversão de tipos com `int()`
- Operadores aritméticos (`+`, `-`, `*`, `/`)
- Leitura de erros: `NameError` e `TypeError`

## Arquivos

| Arquivo | O que faz |
|---|---|
| `ola_mundo.py` | Meu primeiro programa com `print()` |
| `dois_prints.py` | Duas mensagens, uma por linha |
| `pergunta.py` | Pergunta o nome e responde |
| `duas_perguntas.py` | Pergunta nome e cidade |
| `apresentacao.py` | Pergunta nome e idade e monta uma frase |
| `tipos.py` | Mostra os tipos com `type()` |
| `tipo_input.py` | Prova que `input()` devolve texto |
| `ano_nascimento.py` | Converte a idade e calcula o ano de nascimento |
| `calculadora.py` | Soma, multiplicação e divisão de dois números |
| `revisao.py` | Exercício sobre a ordem de leitura e `NameError` |

## Como rodar

1. Instale o Python.
2. Abra a pasta no VS Code.
3. No terminal, rode:

```
python nome_do_arquivo.py
```
